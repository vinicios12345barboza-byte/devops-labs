# 🐧 Trilha de Linux & Shell Script

Este diretório contém anotações, guias de referência e laboratórios práticos sobre administração de sistemas Linux, comandos essenciais e automação no terminal via WSL2 (Ubuntu).

## 📂 Estrutura do Diretório
- `comandos.md`: Cheatsheet de comandos rápidos divididos por categoria.
- `labs/`: Laboratórios práticos com cenários reais, passo a passo e evidências de execução.

## 🎯 Objetivos de Estudo
- Domínio de navegação, manipulação e busca de arquivos no terminal (CLI).
- Gerenciamento de permissões octais e princípios de segurança (`chmod`/`chown`).
- Análise e tratamento de logs com `tail`, `grep` e direcionadores.
- Automação de tarefas usando Shell/Bash Script.
